# Alpha Feedback

## Alpha Test Quick Start

Thank you for testing Evolith.

### Goal

Run Evolith on a repository you know well and evaluate whether the reconstructed features match your understanding of the project's history.

### Commands

```bash
evolith collect git
evolith features rebuild
evolith runs list
evolith runs show 0
evolith features list
evolith features explain <id>
```

### What to Look For

1. Do the reconstructed features correspond to real work streams?
2. Are the feature names meaningful?
3. Does the explanation help you understand why events were grouped together?
4. Do the health indicators feel accurate?
5. Did Evolith suggest anything you would actually change in your workflow?

### Include With Feedback

Please paste:

- Output of `evolith runs show 0`
- Output of one accurate feature explanation
- Output of one inaccurate/confusing feature explanation

This helps us improve reconstruction quality.
